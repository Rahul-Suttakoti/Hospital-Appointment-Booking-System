Developed a custom appointment management system from scratch in C++, focusing on efficient memory handling and clean
data organization. Engineered a real-time priority scheduling engine using a Min-Heap to triage walk-in patients by urgency,
achieving O(log n) insertion/extraction vs. O(n) in a naive list-based approach. Designed a reliable file-handling system using
CSV serialization so patient records persist across restarts, with robust error-checking to keep data secure and organized
under heavy load.
